# PJ's Pizza & Takeaway – TV Menu Wall

| TV | URL |
|---|---|
| Left – Pizzas & Deals | `/1` |
| Middle – Burgers, Hot Dogs, Yiros & Hot Packs | `/2` |
| Right – Fish & Chips + shop info | `/3` |

`/` shows all three side by side.

**Change a price:** edit `menu.js`, then in Terminal:
    git add . && git commit -m "price update" && git push
Vercel redeploys in ~30 seconds. Refresh the TVs.
